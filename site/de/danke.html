Dein erster Start

  1. ZIP entpackenEntpacke StemTagger.zip in einen beliebigen Ordner und starte StemTagger.exe. Keine Installation nötig.
  2. Windows warnt?Zeigt Windows „Der Computer wurde durch Windows geschützt“, klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.
  3. Stem-Dateien oder MP3s hineinziehenTitel, Interpret und Cover eintragen und auf Speichern. Audio, Stems und Traktor-Daten bleiben unverändert.
