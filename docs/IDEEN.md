Lose Ideen, nicht eingeplant. Was eingeplant ist, steht in der [ROADMAP](../ROADMAP.md).

- Weitere Formate nach MP3: FLAC (Vorbis-Kommentare), M4A/AAC (gleiche iTunes-Tags wie `.stem.mp4`).
- Tags aus dem Dateinamen nach eigenem Muster (z. B. `%track% - %artist% - %title%`).
- Cover aus einer Bilddatei im selben Ordner übernehmen (`cover.jpg`, `folder.jpg`).
- Tags von der MP3 auf die daraus erzeugte Stem-Datei übertragen.
